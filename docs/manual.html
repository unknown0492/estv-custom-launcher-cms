esTV Custom Launcher

A home screen for hotel esTV boxes that are not used by guests (staff, signage, back-office TVs). You run it from one CMS on the hotel's own PC: wallpaper, buttons, screen size, the auto-start app and app updates for every box.

On every box

Custom Launcher app

Android home screen com.excel.estvlauncher.custom. It shows the wallpaper, a Menu button and the app buttons, and checks in with the CMS every 5 minutes.

On a hotel PC

Custom Launcher CMS

A web page on a Windows PC on the hotel LAN, port 4053. You manage all of the hotel's boxes here. It starts with Windows.

On eslink.online

CMS IP page

Other Products › Custom Launcher › CMS IP. It stores each hotel's CMS address, so a box that lost its CMS can find it again. Sign-in to the CMS also uses eslink accounts.

●How it works

  • Check-in. Every 5 minutes, at start-up, when the network comes up and on Check Now, the box sends its MAC, IP, name, versions and screen modes to the CMS. The CMS answers with what the box should have: wallpaper, buttons, display, auto-start app and APK updates.
  • Changes reach the boxes within 5 minutes. Press Check Now in a box's Secret Menu to get them at once. After an install or a display change the box reports back straight away.
  • No passwords on the CMS PC. People sign in with their own eslink account. The CMS stores no eslink secret.
  • Lost CMS? If a box can't reach its CMS (for example the PC got a new IP), it asks eslink for the hotel's CMS IP, saves it and tries again.

●Before you start

CMS PC

  • Windows 10 or 11 PC that stays on, on the same LAN as the boxes.
  • A fixed IP (static, or reserved on the router/DHCP). New boxes look for 172.19.0.3:4053, so use that IP if you can.
  • An administrator account on the PC (the installer asks for elevation).
  • Internet access during installation (GitHub, Node.js, Git, ADB).

Accounts and boxes

  • An eslink account with the role esTV Custom Launcher and access to the hotel's property.
  • esTV boxes (Android). Root is recommended: updates then install silently.
  • The launcher APK, for example esTV_Custom_Launcher_v1.0.4-release.apk.
  • For the first install on a box: ADB on a laptop, and network ADB (port 5555) on the box.
i

Plan the IP first. Every box must reach http://<CMS IP>:4053. The installer opens TCP 4053 in Windows Firewall; a hotel firewall between VLANs must allow it too.

1Install the CMS

  1. Open a normal Command Prompt (cmd) on the CMS PC Not PowerShell ISE. You don't need to start it as Administrator; the installer asks for it.
  2. Paste this line and press Enter 
    powershell -NoProfile -ExecutionPolicy Bypass -Command "[Net.ServicePointManager]::SecurityProtocol='Tls12'; irm https://files.estv.cloud/estv-custom-launcher-cms/installer/install.ps1 | iex"
  3. Allow the Administrator prompt The installer now runs these steps by itself and prints a summary at the end:
    StepWhat it does
    ToolsInstalls Git, Node.js LTS and ADB (Android platform-tools) when they are missing.
    CMSDownloads the CMS from GitHub into <drive>:\estv-custom-launcher-cms, or updates it there.
    PM2Runs the CMS in PM2 and starts it with Windows.
    FirewallAllows incoming TCP 4053 (boxes and the web page).
    ShortcutsAdds Custom Launcher CMS (opens the web page) and Start Custom Launcher CMS to the Desktop.
    Web pageOpens http://localhost:4053 in the browser.
  4. Check the summary Every line should be OK. A WARN line tells you what to do, for example "use the Start shortcut on the Desktop".
✓

Updating later is the same line. Running it again updates the CMS and keeps data\: the database, wallpaper, APKs and the chosen property.

2First sign-in

  1. Open the web pageOn the CMS PC use the Desktop shortcut Custom Launcher CMS. From another PC open http://<CMS IP>:4053.
  2. Sign in with your eslink user ID and passwordThe CMS checks them on eslink.online. It needs internet for sign-in.
  3. Choose the hotelThe very first sign-in on a new CMS shows Hotel (eslink property) in the same form. Pick the property and sign in. It is stored on the CMS; later sign-ins skip this.
  4. Open SettingsCheck This CMS: the property, and the address boxes use to reach this PC.
!

Too many failed sign-ins. 10 wrong passwords within 5 minutes from one computer lock sign-in on that computer for up to 5 minutes. Wait, then try again with the right password.

You are signed out after 12 hours without using the page. Change property on the Settings page moves the CMS to another hotel; the boxes then get that hotel's property at their next check-in.

3Set the CMS IP on eslink

This is the safety net: a box that can't reach its CMS asks eslink where the CMS is.

  1. Sign in to eslink.onlineYour account needs the role esTV Custom Launcher.
  2. Open Other Products › Custom Launcher › CMS IPChoose the hotel.
  3. Enter the CMS addressCMS IP / host name = the CMS PC's LAN IP (for example 172.19.0.3), Port = 4053. Save.
i

The fallback only works on a box that checked in with this hotel's CMS at least once, because the box needs to know its property ID. Update this page whenever the CMS PC changes IP.

4Set up a box

  1. Install the launcher APK From a laptop with ADB, on the same network as the box: 
    adb connect <box IP>:5555
adb install -r esTV_Custom_Launcher_v1.0.4-release.apk
    The launcher is signed with the same key as esTVLauncher. Later versions come from the CMS by themselves (see APK updates).
  2. Make it the home screen Press Home on the remote, choose esTV Custom Launcher and Always. Or, over ADB: 
    adb shell cmd package set-home-activity com.excel.estvlauncher.custom/.HomeActivity
  3. Open the Secret Menu On the home screen select Menu (the first button) and press OK. There is no PIN: these TVs are for staff.
  4. Set the CMS IP / Port Only if the CMS is not at the default 172.19.0.3:4053. Enter the CMS PC's IP, then the port.
  5. Give the box a name Box Name › Set Box Name, for example "Lobby TV 1". This name is shown in the CMS box list.
  6. Turn on the Permission Helper Permission Helper › Off - Turn On. It presses Install and Allow on the Android installer screens, so updates finish without a remote when root can't be used.
  7. Press Check Now Last Check-in should show OK (CMS …), and Property ID / Property Name show the hotel. The box now appears on the CMS Boxes page.

●Home screen

  • Move with the arrow keys and press OK to open an app.
  • A button whose app is not installed shows "… is not installed on this box". Upload the app on APK updates and the box installs it.
  • With no app buttons set, only Menu is shown.

●Auto-start on the box

After start-up

The box waits the start delay (default 10 s, set on the CMS), showing a countdown. Then it opens the app. Any key on the remote cancels the countdown, so a technician can reach the Secret Menu.

When the app was closed

If the home screen stays untouched for the relaunch time (default 10 minutes, 0 = never), the countdown starts again and the app reopens. A key press restarts the wait; the Secret Menu pauses it.

●CMS: Boxes

Every box that has checked in, with its name, MAC, IP, last check-in, launcher and button-app versions, display, auto-start app and update state.

  • Search by name, MAC or IP. Click a column heading to sort. CSV exports the list; ↻ reloads it.
  • Updates column: Waiting an APK is still to be installed, Failed hover for the reason, nothing when the box is up to date.
  • Display and Auto-start: click to give this one box its own setting, or set it back to Hotel setting.
  • A box that hasn't checked in for a while shows its last check-in time in the past. It is off, out of the network, or pointing at another CMS.

●CMS: Wallpaper

  • Upload a new wallpaper: a JPG or PNG, ideally 1920 × 1080 (16:9).
  • Use the built-in wallpaper removes the hotel wallpaper; boxes go back to the launcher's own.
  • Boxes download the new picture at their next check-in, only when it changed.

●CMS: Display

Screen size

Don't change (each box keeps its own) or Set every box to a percentage. Lower it when the picture's edges are cut off by the TV (overscan); 100% is the full picture.

Resolution

The list holds the resolutions the boxes' TVs report, such as 720P 60Hz, 1080P 60Hz. A box whose TV doesn't support the chosen one keeps its own.

  • Set one box differently from its row on the Boxes page.
  • A box applies a new setting once. If it fails, the box doesn't keep retrying (the picture would flicker); Check Now applies it again.

●CMS: Auto-start

FieldMeaning
Auto-start app of every boxNone, an app the boxes have, or Other app… to type a package name and start activity.
Start delaySeconds after start-up before the app opens (0–120, default 10).
Open again afterMinutes on the home screen before the app opens again (0 = never, up to 1440, default 10).

Changing only the timings keeps the apps chosen in the boxes' Secret Menus. Changing the app sends it to every box that uses the hotel setting.

●CMS: APK updates

  1. Upload an APKThe launcher itself or any app. The CMS reads its package name and version.
  2. Leave it ActiveEvery box gets the newest active APK of each app when its installed version is lower or the app is missing.
  3. Watch the progressEach APK shows done / total boxes and failures. Open it to see every box: Installed Waiting Failed.
  • The box downloads the file, checks it, and installs it as root. Without root it uses the Android installer, and the Permission Helper presses Install.
  • A failed install isn't retried until you upload a different APK or press Check Now on the box.
  • Install via ADB on a box row is a backup: the CMS PC installs the APK over network ADB (port 5555 on the box).
  • Turn Active off to stop an update. Delete removes the APK from the CMS; boxes keep what they installed.
!

An APK can only replace an app signed with the same key. A launcher APK must come from the esTV Custom Launcher release build.

●CMS: Settings

This CMS

The hotel (property) and the address boxes use to reach this PC, plus the CMS version. Change property moves this CMS to another hotel.

ADB (backup install)

The adb.exe used by Install via ADB and its version. Leave the path empty: the CMS finds the adb the installer set up.

●Which setting wins

  • Display: a box's own setting on the CMS beats the hotel setting.
  • Buttons and auto-start app: a change in the Secret Menu stays until someone changes that setting on the CMS again. Then the CMS setting applies.
  • Auto-start timings (delay, relaunch) always come from the CMS.

●Updating

The CMS

Run the install line again on the CMS PC. It updates the program and restarts it; boxes and settings are kept. The version is shown on the page footer and on Settings.

The launcher on the boxes

Upload the new launcher APK on APK updates. Each box installs it within 5 minutes and restarts its home screen. Follow it on the APK row.

●Troubleshooting

A box doesn't appear on the Boxes page
  1. In the Secret Menu check IP Address (network up?) and CMS IP / Port.
  2. Press Check Now, then select Last Check-in to read the error.
  3. From another PC on the boxes' network open http://<CMS IP>:4053. If it doesn't load, check the CMS is running (Desktop shortcut Start Custom Launcher CMS) and the firewall allows TCP 4053.
The web page doesn't open

Double-click Start Custom Launcher CMS on the Desktop of the CMS PC and wait a few seconds. If it still fails, run the install line again; it repairs the installation and keeps the data.

Sign-in fails
  • Wrong user ID or password: try your eslink sign-in on eslink.online.
  • No access / no properties: your eslink account needs the role esTV Custom Launcher and the hotel's property.
  • "Too many failed sign-ins": wait the minutes shown, then try again.
  • "eslink.online cannot be reached": the CMS PC has no internet. Sign-in needs it; the boxes don't.
An APK update shows Failed or stays Waiting
  • Hover the Failed badge for the reason. A signature mismatch means the APK is signed with a different key than the installed app.
  • On a box without root, turn the Permission Helper on in the Secret Menu, then press Check Now.
  • A box that stays Waiting hasn't checked in yet: check its last check-in.
  • As a backup use Install via ADB on that box's row.
The picture is cut off or the resolution is wrong

Lower the screen size (for example 92%) on the Display page, or for one box on the Boxes page. Press Check Now on the box to apply it at once. Only resolutions the box's TV reports can be set.

The auto-start app doesn't open
  • Check Auto-start App in the Secret Menu: it must show an app, not None.
  • The countdown is cancelled by any key, including a key press during start-up.
  • Make sure the Custom Launcher is the default home screen (step 2 of box set-up).
  • The relaunch only runs while the home screen is shown and the relaunch time is not 0.
The CMS PC got a new IP address

Give the PC its old IP back (best), or update CMS IP on eslink. Boxes that checked in before find the new address through eslink by themselves. New boxes need it typed in their Secret Menu.

The box shows a MAC starting with 02:

Android 10 hides the real MAC from apps without root. The launcher then uses a fixed stand-in made from the box's Android ID. It stays the same, so the box keeps its row on the CMS.
